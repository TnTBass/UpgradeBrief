Challenge

Vulnerabilities in Veeam ONE Agent components residing on Veeam ONE and Veeam Backup & Replication servers allow executing malicious code remotely without authentication.

Severity: critical

CVSS v3 score: 9.8

Cause

The deserialization issues are tracked as CVE-2020-10914 and CVE-2020-10915.

Solution

Hotfixes are available for Veeam ONE 10 build 10.0.0.750 and 9.5 Update 4a build 9.5.4.4587.
