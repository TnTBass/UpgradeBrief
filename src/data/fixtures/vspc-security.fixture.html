All vulnerabilities disclosed in this section affect Veeam Service Provider Console 8.1.0.21377 and all earlier versions 8 and 7 builds.

CVE-2024-42448

From the VSPC management agent machine, under the condition that the management agent is authorized on the server, it is possible to perform Remote Code Execution on the VSPC server machine.

Severity: Critical

CVSS v3.1 Score: 9.9

CVE-2024-42449

From the VSPC management agent machine, under the condition that the management agent is authorized on the server, it is possible to leak an NTLM hash and delete files on the VSPC server machine.

Severity: High

CVSS v3.1 Score: 7.1

Solution

These vulnerabilities were fixed starting in Veeam Service Provider Console 8.1.0.21999.
