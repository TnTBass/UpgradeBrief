Severity: Critical

A vulnerability in Veeam Service Provider Console allows an unauthenticated attacker to hijack the password reset link and take over a user account.

Severity: Medium

These vulnerabilities were fixed starting with Veeam Service Provider Console 9.2.1.33875.
