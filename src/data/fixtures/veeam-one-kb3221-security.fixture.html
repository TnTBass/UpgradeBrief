Challenge

XML External Entity Processing vulnerabilities in Veeam ONE Reporter make it possible to read arbitrary files without authentication.

Severity: critical

CVSS v3 score: 7.5

Cause

The vulnerabilities are tracked as CVE-2020-15418 and CVE-2020-15419.

Solution

Hotfixes are available for Veeam ONE 10 build 10.0.0.750 and 9.5 Update 4a build 9.5.4.4587.
