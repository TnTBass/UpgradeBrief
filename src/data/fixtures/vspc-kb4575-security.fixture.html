CVE-2024-29212

Due to an unsafe deserialization method used by the VSPC server, under certain conditions it is possible to perform Remote Code Execution on the VSPC server machine.

This vulnerability was detected during internal testing.

Severity: Critical

CVSS v3.1 Score: 9.9

Solution

The vulnerability was fixed starting in Veeam Service Provider Console 7.0.0.19551 and Veeam Service Provider Console 8.0.0.19552.
