Article Updates Veeam is investigating these vulnerabilities and will update this article as new information becomes available. Summary nginx2root is the common name for five memory corruption vulnerabilities in nginx: CVE-2026-123007, CVE-2026-123633, CVE-2026-121810, CVE-2026-123634, and CVE-2026-113425. They affect the HTTP/2 module, the HTTP/3 module, the DNS resolver, and the mail proxy, and can be triggered remotely. Combined with a Linux kernel vulnerability, they can lead to root access. Windows-based installations of Veeam Backup & Replication and Veeam Backup Enterprise Manager do not use nginx and are not affected. Veeam Software Appliance and Veeam Infrastructure Appliance include nginx and are listed in the following table. Whether a Veeam component is affected depends on the nginx build it includes and the nginx features its configuration enables. A fixed nginx package is not yet available. The fixed package will be delivered through Veeam Updater , and this article will be updated when it is available. HTTP/2 cannot be disabled on these appliances because Veeam components depend on it. Until the fixed package is installed, restrict access to TCP port 443 on the appliances to trusted networks. Public Cloud Appliances The Veeam Plug-In for AWS , Veeam Plug-In for Google Cloud , and Veeam Plug-In for Microsoft Azure appliances run Ubuntu 22.04 LTS and use the nginx package provided by Ubuntu. The patched nginx package ( 1.18.0-6ubuntu14.23 ) is installed with the security updates offered through Veeam Updater . Worker instances do not include nginx and are not affected. To remediate the vulnerabilities, install all available security updates through Veeam Updater. Veeam Data Cloud Veeam manages the infrastructure of Veeam Data Cloud for Salesforce , Veeam Data Cloud for Microsoft Azure , and Veeam Data Cloud for AWS , and is remediating the affected services. No customer action is required. Veeam Backup for Salesforce Veeam Backup for Salesforce 3.2.1 uses the nginx package provided by the operating system of the server where it is installed, and generates the nginx configuration. That configuration enables HTTP/2 on a listener that proxies requests to a backend, so CVE-2026-123007 and CVE-2026-123633 apply. The remaining vulnerabilities do not apply to this configuration. Veeam does not manage the operating system or the nginx package on customer-deployed Veeam Backup for Salesforce servers. Customers managing these servers are advised to review the advisory from the operating system vendor and install the nginx update when it is available. Until the nginx update is installed, HTTP/2 can be disabled to remediate the vulnerabilities: On the Veeam Backup for Salesforce server, open the following file: /etc/nginx/sites-available/vbsf-frontend.conf Remove the http2 parameter from the listen directive for port 443.
